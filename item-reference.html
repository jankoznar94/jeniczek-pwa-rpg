🏗️ Base itemy

Každý base item má fixní jméno a staty. Při lootu se na něj nabalují affixy (prefixy + suffixy). Tier určuje, v jak hlubokém patře se item může objevit.

🔧 Affixy (módy)

Affixy se dělí na prefixy (před jménem) a suffixy (za jménem). Stejná group = affixy se vzájemně vylučují. minIlvl = minimální monster level pro výskyt. Weight = relativní pravděpodobnost výběru.

🌟 Unique itemy

Unique itemy mají fixní sadu affixů a vlastní jméno. Objevují se pouze jako boss dropy.

⚙️ Generovací pravidla

🎲 Quality roll
Normal — 0 affixů (base item)
Magic — 1-2 affixy (1 prefix + 1 suffix max)
Rare — 3-4 affixy (2 prefix + 2 suffix max)
Unique — fixní sada affixů

🧮 Výběr affixu
  1. Filtruj affixy: minIlvl <= monsterLevel + kompatibilní typ slotu
  2. Rozděl na prefixy a suffixy
  3. Odeber affixy ze skupin, které už jsou použité (group exkluzivita)
  4. Vyber weighted random podle weight
  5. Roll hodnotu v rozsahu [min, max]
📐 Level requirement

lvlReq = floor(0.75 × max(minIlvl všech affixů na itemu))

📛 Skládání názvu

[prefixy mezera] + [base jméno] + [mezera suffixy]
Příklad: Ohnivý Široký meč Moci
