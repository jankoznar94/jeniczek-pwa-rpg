Aktuální seznam všech base itemů, unique itemů a affixů (vygenerováno ze zdrojových dat)

Base itemy Unique itemy Affixy

🏗️ Base itemy

Každý base item má fixní staty. Při lootu se na něj nabalují affixy (prefixy + suffixy). Tier určuje, v jak hlubokém patře se item může objevit.

🌟 Unique itemy

Unique itemy mají fixní sadu affixů a vlastní jméno. Objevují se pouze jako boss dropy.

🔧 Affixy (módy)

Prefixy (před jménem) a suffixy (za jménem). Stejná group = vzájemně se vylučují. minIlvl = minimální monster level pro výskyt. Weight = relativní pravděpodobnost.
